# Агент цен

Что пользователь написал после `/prices`: `$ARGUMENTS`

Ты координатор. Сам цены не ищешь и цифры не считаешь: ищут субагенты, считает Python
(`price_agent.py`). Всё работает по подписке Claude, API-ключ не нужен.

## Шаг 1: подготовка

Возьми из аргументов id товаров (слова без `--`). Если их нет, проверяются все товары.

```bash
python main.py prices init <id ...>
```

Команда печатает папку проверки и путь к брифу для каждого товара.

## Шаг 2: исследователи

Запусти по одному субагенту на каждый бриф, **все в одном сообщении**
(Agent tool, `subagent_type: general-purpose`):

- `description`: `цены <id>`
- `prompt`: `Прочитай файл <путь к брифу> и выполни его точно. Это весь твой бриф.`

Субагенты не видят этот разговор. Бриф самодостаточный: ничего к нему не добавляй и не меняй.
Дождись, пока закончат все.

## Шаг 3: проверка

```bash
python main.py prices check "<папка проверки>"
```

Если кто-то не сдал файл или файл с ошибкой, запусти для этих товаров субагентов ещё раз
(один раз, с тем же брифом). Никогда не пиши файлы `offers/*.json` за исследователей.

## Шаг 4: отчёт

```bash
python main.py prices report "<папка проверки>"
```

Добавь `--no-send`, если он есть в аргументах. Команда считает цифры, сохраняет `report.txt`
в папке проверки и отправляет отчёт в личный Telegram (`ADMIN_CHAT_ID`), не в канал.

## Шаг 5: ответ пользователю

Коротко, по-русски: по каждому товару — медиана рынка и где наша цена, что изменилось
с прошлой проверки, отправлен ли отчёт и путь к `report.txt`. Бери цифры только из вывода
команды `report`: не добавляй свои и не пересчитывай.

## Правила

- Не выдумывай цены, продавцов и ссылки. Не правь файлы исследователей.
- Ничего не публикуй в Telegram-канал.
- Если пользователь просит добавить или поменять товар — правь `price_watch.json`
  (поля описаны в `PRICE_AGENT.md`). Себестоимость товара — в `sebestoimost.json` (скил `/sebestoimost`).
