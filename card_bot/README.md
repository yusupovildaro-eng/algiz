# Бот карточек товара для Telegram и Instagram

Присылаете боту фото, скриншот или ссылку на товар и пишете цену. Бот сам убирает фон, выравнивает свет и цвет, добавляет тень и показывает карточку в 5 стилях. Вы выбираете стиль и получаете:

- карусель 4:5 (1080×1350): обложку, остальные фото в том же оформлении и финальный слайд с ценой, размерами и строкой «как заказать»;
- сторис 9:16;
- готовый текст поста для Telegram (с ценой, скидкой, размерами и хэштегами) и отдельно для Instagram (нажать, чтобы скопировать);
- кнопку «Опубликовать в канал».

## Стили

Стили собраны по разбору самых кликабельных карточек: лидеры Wildberries/Ozon, fashion-журналы, сникер-ресейл, интерьерный Pinterest, промо бьюти-брендов.

| № | Стиль | Для чего | Откуда приём |
|---|---|---|---|
| 1 | **Студия** | подходит всему | маркетплейсы: товар занимает ~80% кадра, контрастный однотонный фон, минимум текста |
| 2 | **Журнал** | одежда, бренды | fashion-журналы: крупное слово антиквой за товаром, тонкая рамка, «quiet luxury» |
| 3 | **Дроп** | кроссовки, стритвир | сникер-ресейл: яркий фон в контраст товару, огромный шрифт, ценник-стикер |
| 4 | **Дом** | посуда, текстиль | Pinterest-интерьер: лён, солнечная тень от окна, этикетка |
| 5 | **Акция** | скидки, косметика | промо бьюти-брендов: ягодный градиент, крупная скидка, цена в белой «кнопке» |

Что вытекает из исследований и учтено в шаблонах:
- формат 4:5 занимает больше всего места в ленте;
- товар крупный и чётко отделён от фона (белое на белом теряется, поэтому фон подбирается под цвет товара);
- на обложке одна главная мысль и мало текста;
- автокоррекция яркости, контраста и резкости (по тесту Rakuten давала +15–17% к CTR в fashion).

## Что умеет с фото

- **Обычные фото** с телефона: вещь на кровати, на вешалке, на полу.
- **Скриншоты страниц магазинов**: бот сам находит товар, убирает строку браузера, кнопки и текст. Дуэты и наборы остаются вместе.
- **Ссылки на товар**: бот скачивает с сайта оригинальное фото (обычно 1500–2000 px, это в 3–4 раза чётче скриншота) и берёт название со страницы. Если сайт не пускает ботов, пришлите скриншот.
- Если вещь обрезана краем кадра или фон не отделился, фото ставится аккуратной карточкой без вырезания. Кнопка «✂️ Не вырезать фон» делает так для всех фото.
- **Фон под товар.** Цвет фона берётся из цветов самой вещи: золото даёт бронзу, розовые тени — винный, беж — мокко, синее — глубокий синий. В «Дропе» фон, наоборот, контрастный.
- **Логотип.** Команда `/logo`, затем пришлите аватарку канала: бот вырежет круг и поставит его в угол каждой карточки.

Zara, H&M и часть других крупных магазинов закрыты от ботов защитой Akamai, поэтому по ссылке они не откроются. Для них присылайте скриншот страницы товара.

## Описание товара

Без ИИ бот собирает русское название и короткий продающий текст по словарю:
- «Draped tulle midi dress» → «Платье миди из тюля с драпировкой»;
- описание: «Лёгкий воздушный тюль и эффектная драпировка. Подойдёт и для вечера, и для праздника — а с жакетом и для офиса. Размеры ограничены — пишите, отложим для вас.»

С ключом `ANTHROPIC_API_KEY` описание пишет Claude, и оно получается живее и точнее.

## Формат текста

Каждый пункт с новой строки (или в одну строку через запятую):

```
Кроссовки Nike Air Force 1
было 1 800 000 стало 1 450 000
40, 41, 42, 43
Оригинал
Из Европы
```

- Название, цену и размеры бот распознаёт сам: «12 900», «$120», «49,99 €», «S M L», «40-44», «one size».
- Строки после названия становятся плашками («Оригинал», «Из Италии»).
- Если прислали ссылку, достаточно написать только цену.

## Установка и запуск

### 1. Создайте бота
Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и скопируйте токен.

### 2a. Windows (на своём компьютере)
1. Установите Python 3.11–3.13 с python.org (галочка «Add to PATH»).
2. Дважды щёлкните `run_card_bot.bat` в корне репозитория. Первый запуск ставит зависимости, это 5–10 минут.
3. Откроется `card_bot\.env`. Впишите `CARD_BOT_TOKEN`, сохраните и запустите `.bat` снова.

Бот работает, пока открыто окно и включён компьютер.

### 2b. Сервер (VPS с Ubuntu), чтобы бот работал круглосуточно
```bash
git clone <репозиторий> && cd algiz
python3 -m venv .venv && . .venv/bin/activate
pip install -r card_bot/requirements.txt
cp card_bot/.env.example card_bot/.env && nano card_bot/.env   # впишите токен
python -m card_bot
```
Для автозапуска оформите это как сервис systemd. Хватит VPS с 2 ГБ RAM.

### 3. Настройте в самом боте
- `/start`: первый, кто нажал, становится владельцем. Чужие пользоваться ботом не смогут.
- `/shop Название магазина`
- `/contact @ваш_ник` — куда писать для заказа.
- `/currency сум` (или `$`, `€`, `₽`)
- `/channel @ваш_канал` — сначала добавьте бота в администраторы канала.
- `/logo` — логотип на карточки (`/logo off` — убрать).
- `/settings` — посмотреть текущие настройки.

### 4. Тексты от ИИ (по желанию)
Если вписать `ANTHROPIC_API_KEY` в `.env`, Claude будет:
- читать название товара со скриншота;
- писать 2–3 живых предложения к посту;
- подбирать хэштеги.

Цену и размеры ИИ не трогает. Без ключа текст собирается по шаблону.

## Скорость

Первый запуск скачивает модель удаления фона (~220 МБ). Дальше одно фото обрабатывается за 5–15 секунд на обычном процессоре. Если нужно быстрее, поставьте в `.env` `REMBG_MODEL=isnet-general-use`: это в 2–3 раза быстрее, но края чуть грубее.

## Проверка без Telegram

```bash
python -m card_bot.demo фото1.jpg фото2.jpg --text "Nike Air Force 1, 1 450 000, 40-44" --out card_out
```
В папке `card_out` появятся превью всех стилей, слайды, сторис и текст поста.
