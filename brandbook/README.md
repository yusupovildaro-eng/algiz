# Брендбук ALOQA.uz: логотип на радиостанциях

Документ для завода-производителя раций (OEM): какие версии логотипа наносить, куда, какого размера, какой технологией и как принимать образец. Текст на русском и английском.

| Файл | Что это |
|---|---|
| `ALOQA-radio-brandbook.pdf` | Брендбук, 9 страниц A4. Его отправляем на завод. |
| `index.html` | Исходник брендбука (из него собирается PDF). |
| `logo/*.svg` | Логотипы в нужных цветах: компактный (основной для рации), белый, значок, версии со слоганом RU/UZ. |
| `logo/traced/` | Мастер-файлы трассировки (группы `ink` и `accent`). |
| `img/` | Фото раций без чужих логотипов, для визуализаций. |
| `tools/` | Скрипты сборки. |

## Важно про SVG

Файлы в `logo/` получены трассировкой PNG-макета логотипа. Для экрана и согласования их достаточно. Для печати на заводе лучше отправить исходные векторные файлы дизайнера (AI или PDF, текст в кривых); имена в брифе на стр. 9 можно заменить на них.

## Сборка

```bash
cd brandbook
python3 -I tools/export_logos.py   # цветовые версии logo/*.svg + вставка <symbol> в index.html
node tools/build-pdf.js            # index.html -> ALOQA-radio-brandbook.pdf (нужен Playwright + Chromium)
```

Пересоздать трассировку из PNG (нужен `potrace`):

```bash
python3 -I tools/vectorize.py panel.png logo/traced/compact.svg bg=0,0,0 layer=ink:255,255,255 layer=accent:242,112,14
```
