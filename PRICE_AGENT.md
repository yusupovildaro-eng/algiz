# Агент цен и себестоимость

Два скила для Claude Code. Работают по вашей **подписке Claude** — API-ключ Anthropic не нужен.

| команда в Claude Code | что делает |
| --- | --- |
| `/sebestoimost` | составитель себестоимости: сколько стоит привезти 1 шт и какая маржа |
| `/prices` | агент цен: почём конкуренты в Узбекистане продают ваши товары |

Скилы лежат в `.claude/skills/` этого проекта: они появляются сами, когда вы открываете
папку проекта в Claude Code (приложение или терминал).

## Установка на компьютер (один раз)

1. Обновите папку проекта `C:\Users\yusup\tg-migalki-bot` из GitHub (эта ветка).
2. Установите Claude Code и войдите своим аккаунтом Claude (подписка Pro/Max).
   На Windows для команд Claude Code нужен Git for Windows (Git Bash).
3. `pip install -r requirements.txt` (как для бота).
4. Для отчётов в Telegram добавьте в `.env` строку `ADMIN_CHAT_ID=<ваш id>`:
   - откройте вашего бота в Telegram (тот, чей `BOT_TOKEN` в `.env`) и нажмите «Start»;
   - откройте в браузере `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`
     и найдите `"chat":{"id":123456789` — это число и есть ваш id.

Весь пакет founder-skill (11 скилов: совет директоров, панель покупателей, маркетинг…)
при желании ставится отдельно, в Claude Code:

```
/plugin marketplace add Jakeschincariol/founder-skill
/plugin install founder-skill@founder-skill
```

Для себестоимости он не нужен: `/sebestoimost` — это его `founder-cfo`, переделанный под импорт,
сумы и налоги Узбекистана.

## Себестоимость — `/sebestoimost`

Напишите в Claude Code, например: `/sebestoimost посчитай маяк Цефей: закупка 8250 руб,
доставка партии 50 шт — 3 млн сум, продаю за 1 900 000`. Claude заполнит `sebestoimost.json`,
спросит недостающее и запустит расчёт. Можно и без Claude: `python sebestoimost.py`.

Как считается одна штука (в сумах):

| статья | формула |
| --- | --- |
| закупка | цена поставщика × курс ЦБ РУз (подтягивается автоматически) |
| комиссия банка | закупка × `bank_fee_pct` |
| доставка | доставка на 1 шт × курс |
| пошлина | (закупка + доставка) × `duty_pct` |
| таможенный сбор | (закупка + доставка) × `customs_fee_pct` |
| НДС при ввозе | (закупка + доставка + пошлина) × `vat_pct` — в себестоимость, если вы не плательщик НДС |
| прочее | `extra_per_unit` (сертификация, упаковка…) |

Дальше: прибыль с 1 шт и маржа при вашей цене (с налогом с оборота или НДС), цена без убытка,
цена для целевой маржи, таблица «что если» (курс +10%, доставка +20%, пошлина +5 п.п.,
цена −10%), прибыль бизнеса в месяц и точка безубыточности (если заданы продажи в месяц
и постоянные расходы).

Команды без Claude:

```
python sebestoimost.py                                   все товары
python sebestoimost.py --product tsefey --price 1900000  что если цена такая
python sebestoimost.py --rate RUB=160                    что если курс такой
python sebestoimost.py --out reports/sebestoimost/2026-11-12.md
```

В `sebestoimost.json` сейчас **пример**: цены — розничный прайс elina.ru, доставка и пошлина
условные, ставки НДС 12% и налога с оборота 4% — проверьте у бухгалтера. Замените своими.

## Агент цен — `/prices`

1. Claude Code готовит по брифу на каждый товар из `price_watch.json`.
2. Запускает по субагенту-исследователю на товар, параллельно. Каждый ищет в интернете
   (на русском и узбекском, olx.uz, uzum.uz, профильные магазины) и сдаёт файл с ценами и ссылками.
3. Python считает: цены в сумах по курсу ЦБ, минимум / медиана / максимум, ваша позиция,
   себестоимость и маржа (из `sebestoimost.json`, если `id` совпадает), изменение с прошлой проверки.
4. Отчёт уходит **в ваш личный Telegram** (никогда не в канал), копия — в `reports/prices/<дата>/report.txt`,
   история цен — в `posted.db`.

Запуск: в Claude Code — `/prices`, `/prices tsefey ermak` (только эти товары) или
`/prices --no-send` (без отправки).

**Каждую неделю автоматически.** `prices.bat` запускает Claude Code без окна
(`claude -p "/prices"`) с разрешениями только на поиск, чтение сайтов, запись в `reports/`
и команды `python main.py prices`. Сначала запустите `prices.bat` вручную и посмотрите
`logs\prices.log` — так вы проверите, что вход по подписке работает без вас. Потом одна
команда в cmd:

```
schtasks /create /tn "Algiz prices" /tr "C:\Users\yusup\tg-migalki-bot\prices.bat" /sc weekly /d MON /st 09:00
```

Компьютер в это время должен быть включён.

### price_watch.json

`settings`:

| поле | что это |
| --- | --- |
| `company`, `sells` | кто вы и что продаёте — исследователь понимает, что искать |
| `own_domains` | ваши сайты: их не считаем конкурентами |
| `landed_cost_pct` | надбавка к закупке, %, если товара нет в `sebestoimost.json` (`null` — без надбавки) |
| `target_offers` | сколько предложений искать на товар |
| `max_searches`, `max_fetches` | лимит поисков и открытых страниц на товар |
| `manual_rates` | курсы на случай, если сайт ЦБ недоступен, например `{"USD": 12000}` |

`items` — по одному на товар: `id`, `name`, `query` (что искать), `analogs`,
`our_price_uzs` (ваша цена; если `null` — берётся `sale_price_uzs` из `sebestoimost.json`),
`supplier_price` и `supplier_currency` (если товара нет в `sebestoimost.json`).

### Ограничения

- Агент видит то, что опубликовано на сайтах. Цены в Telegram-каналах и «по запросу» он не найдёт.
- Цена на сайте — не всегда цена сделки (опт, скидки, НДС). Перед решением откройте ссылку.
- Если найдены только аналоги, отчёт так и пишет — сравнивайте осторожно.
- Предложения без ссылки, без цены и с ваших сайтов отбрасываются автоматически.
- Поиск расходует лимиты вашей подписки: 4 товара — это 4 субагента с веб-поиском.
