# Агент цен

Раз в неделю (или по команде) проверяет, почём конкуренты в Узбекистане продают
ваши товары, и присылает отчёт **в ваш личный Telegram**. В канал отчёт не уходит никогда.

Как работает:

1. Берёт товары из `price_watch.json`.
2. На каждый товар запускает отдельного исследователя (Claude с веб-поиском),
   несколько товаров параллельно. Исследователь ищет на русском и узбекском,
   открывает страницы магазинов и объявлений (olx.uz, uzum.uz, профильные магазины)
   и сдаёт список предложений со ссылками.
3. Все цифры считает Python, а не модель: перевод в сумы по курсу ЦБ РУз,
   минимум / медиана / максимум, ваша позиция, маржа, изменение с прошлой проверки.
4. Отчёт уходит в `ADMIN_CHAT_ID`, копия сохраняется в `reports/prices/`,
   история цен — в `posted.db` (таблицы `price_runs`, `price_offers`).

## Настройка (один раз)

1. **Обновите библиотеки**: `pip install -r requirements.txt` (нужен `anthropic` 2.8 или новее).
2. **Ключ Anthropic** уже есть в `.env` (`ANTHROPIC_API_KEY`), его использует и бот канала.
3. **Ваш chat id** для отчётов:
   - откройте вашего бота в Telegram (тот, чей `BOT_TOKEN` в `.env`) и нажмите «Start»;
   - откройте в браузере `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates`
     и найдите `"chat":{"id":123456789` — это число и есть ваш id;
   - добавьте в `.env` строку `ADMIN_CHAT_ID=123456789`.
4. **Заполните `price_watch.json`** (см. ниже): главное — ваши цены `our_price_uzs`.

## price_watch.json

`settings`:

| поле | что это |
| --- | --- |
| `company`, `sells` | кто вы и что продаёте — исследователь понимает, что искать |
| `own_domains` | ваши сайты: их не ищем и не считаем конкурентами |
| `landed_cost_pct` | надбавка к цене поставщика на доставку, таможню, НДС, в %. `null` — не учитывать |
| `target_offers` | сколько предложений искать на товар (по умолчанию 8) |
| `max_searches`, `max_fetches` | лимит поисков и открытых страниц на товар — ограничивает расход |
| `manual_rates` | курсы на случай, если сайт ЦБ недоступен, например `{"USD": 12000}` |

`items` — по одному на товар:

| поле | что это |
| --- | --- |
| `id` | короткое имя латиницей: `python main.py prices ermak` |
| `name` | название для отчёта |
| `query` | что искать (как написал бы покупатель) |
| `analogs` | какие товары считать аналогами |
| `our_price_uzs` | **ваша цена в сумах** (`null` — отчёт покажет только рынок) |
| `supplier_price`, `supplier_currency` | цена у поставщика и валюта (`RUB`, `USD`, `TRY`, `CNY`, `EUR`) |

В примере уже стоят товары «Элины» с ценами из прайса elina.ru. Это розничный прайс
производителя, а не ваша закупка: замените на свои цены.

## Запуск

```
python main.py prices                  все товары
python main.py prices ermak tsefey     только эти
python main.py prices --no-send        без отправки в Telegram (отчёт в reports/prices/)
```

Или двойной клик по `prices.bat` (лог в `logs\prices.log`).

**Каждую неделю автоматически** — Планировщик заданий Windows, одна команда в cmd:

```
schtasks /create /tn "Algiz prices" /tr "C:\Users\yusup\tg-migalki-bot\prices.bat" /sc weekly /d MON /st 09:00
```

Компьютер в это время должен быть включён.

## Расходы

Оплата Anthropic за токены и веб-поиски. Точная оценка — в конце каждого отчёта
(«Расход: ≈ $…»). Ориентир для Claude Opus 5.5: примерно $0.5–1.5 за товар, то есть
несколько долларов за проверку 4 товаров. Как удешевить:

- `PRICE_AGENT_MODEL=claude-sonnet-5-5` в `.env` — примерно вдвое дешевле;
- меньше `max_searches` / `max_fetches` в `price_watch.json`;
- проверять реже или только нужные товары.

## Ограничения

- Агент находит то, что видно в интернете. Цены в Telegram-каналах и «по запросу» он не видит.
- Цена на сайте — не всегда цена сделки (опт, скидки, НДС). Перед решением откройте ссылку.
- Если найдены только аналоги, отчёт так и пишет — сравнивайте осторожно.
- Ответы модели проверяются: без ссылки, без цены и с ваших сайтов предложения отбрасываются.
